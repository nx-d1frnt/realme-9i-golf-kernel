# Проверенная сборка ABI v2 — 13 ноября 2026

Устройство: **Realme 9i 4G / RMX3491**. Система: crDroid GSI Android 14.
Исходная рабочая база: штатное ядро 4.19.157-perf+ от 19 ноября 2024,
патченные boot/vendor с отключённым FBE.

## Проверки перед установкой

- Все **2087 импортов 33 vendor-модулей** разрешены с точным совпадением CRC.
- Учтены экспорты аудиомодулей друг для друга; конфликтов провайдеров нет.
- Сохранены MODVERSIONS, проверка подписей и публичный штатный сертификат.
- После упаковки повторная распаковка подтвердила идентичность ramdisk,
  DTB, header и fstab. FBE выключено, checkpoint=fs сохранён.
- Исходные boot и vendor считаны и проверены по SHA-256 перед установкой.

## Проверки на телефоне

Bootloader разблокирован. Команда `fastboot boot` на нём не поддерживается:
образ принимается в RAM, но запуск отклоняется как unknown command.
После отдельного разрешения пользователя тестовый образ записан в boot.

- Android завершил загрузку; фактическая строка ядра совпала с кандидатом.
- Root доступен, userdata смонтирована rw, отключение FBE сохранено.
- Все **31 модуль**, загружавшийся до установки, загрузились после неё.
- USB-зарядка активна; fingerprint HAL deaths=0; camera HAL видит 2 камеры.
- Zram swap активен; хеш vendor остался исходным.
- SHA-256 раздела boot совпал с опубликованным образом.
- Пользователь подтвердил отсутствие замеченных сбоев основных функций.
- За первичную проверку около 6,5 минут kernel panic, Oops и ошибок
  ABI/подписи модулей в считанных логах не найдено.

## Известные ограничения

Это **экспериментальная сборка**. Длительный сон, расход батареи и работа
под нагрузкой ещё не проверены. В журнале обнаружены kernel WARNING:

| Место | Наблюдение |
| --- | --- |
| device_links_driver_bound | Состояние зависимости устройства при probe |
| ___slab_alloc | ION cache использует пустой constructor вместе с zalloc |
| __alloc_pages_nodemask | Zram reclaim: WARN вызывается до Oplus-исключения HIGH_ATOMIC_ZRAM |
| irq_startup | Активация touch IRQ при возобновлении экрана |

Новых мест WARNING после ручной проверки не появилось. Предупреждения
не подавлялись; их наличие требует отдельного анализа перед признанием
сборки стабильной. Выпуск отмечен как prerelease.
