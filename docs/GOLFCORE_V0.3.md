# GolfCore v0.3.0-rc1 Balanced

Дата подготовки: 14 ноября 2026. Устройство: Realme 9i 4G / RMX3491,
crDroid GSI Android 14 и существующая DFE-база.
**Статус: собран и упакован; новое ядро ещё не установлено на телефон.**
Хеши и результаты: [GOLFCORE_V0.3_BUILD.json](GOLFCORE_V0.3_BUILD.json).

## Настоящее имя релиза

`uname -r` кандидата: **4.19.157-GolfCore-v0.3**.
Базовый номер 4.19.157 сохранён: полное обновление stable до версии ядра
донора не выполнялось. В метаданных: `golfcore@balanced-v0.3-rc1`.

Предыдущее предположение об обязательности суффикса `-perf+` было излишне
ограничительным. В используемом `kernel/module.c` функция same_magic при
наличии CRC пропускает сравнение первого поля vermagic, то есть имени
релиза. Остальные поля по-прежнему сравниваются точно, а импорты проверяются
по CRC. Все 33 сохранённых модуля имеют секцию __versions.

Загрузчик не изменён, MODVERSIONS и MODULE_SIG_FORCE сохранены,
MODULE_FORCE_LOAD выключен. check_vermagic.py компилирует фактическую
неизменённую функцию, берёт vermagic из нового kernel/module.o и проверяет
все 33 модуля. Контроли без CRC и с изменённым хвостом vermagic отклоняются.
Отдельный аудит подтвердил точное совпадение всех 2087 импортов.
Никакие бинарные модули и их подписи не редактировались.

## Перенос LZ4 1.10.0

Донор: [Neutrino](https://github.com/Madara273/Redmi-Note-11-Kernel),
ветка Neutrino_r05, commit `9e014b100dfc999ad599337b807af5fffd11f573`.
Взяты только include/linux/lz4.h и библиотека lib/lz4, а не весь kernel 4.19.325.
Исходные SHA-256 донора и применённый патч записаны в SOURCES.json.
BSD-уведомления библиотеки сохранены в исходниках.

Адаптация для нашей базы:

- Условия сборки привязаны к существующим CONFIG_LZ4_COMPRESS,
  CONFIG_LZ4_DECOMPRESS и CONFIG_LZ4HC_COMPRESS. Штатный конфиг сохранён.
- LZ4_compress_fast и LZ4_compress_destSize используют рабочую память
  вызывающего кода. Устранены локальные объекты по 16 KiB из донорской
  реализации, сохранены прежние kernel-сигнатуры этих двух функций.
- Сохранены экспорты decoder API, добавлен прежний alias HC default level.
- Рабочая память обычного компрессора осталась **16416 байт**.
- Ранее использовавшиеся файлы lz4_compress.c/lz4_decompress.c оставлены
  в истории/дереве как справочные; Makefile компилирует новую lz4.c.

Host-тест собирает фактические старые и новые исходники с минимальными
заменами kernel-заголовков. Под AddressSanitizer пройдены **1640** циклов
сжатия/распаковки, в том числе обмен блоками между версиями, и **13380**
проверок выходных буферов, усечённых и случайных повреждённых блоков.
Проверены нулевые, повторяющиеся, случайные и смешанные данные, размеры
от 0 до 128 KiB, включая страницы 4096 байт; workspace API и ограниченный
выход destSize. Дополнительно проверена частичная распаковка, используемая EROFS. Реализации кодеков в host-тесте не переписывались.

```bash
python3 tests/check_lz4.py --old-source /path/to/v02/kernel/msm-4.19 \
  --new-source /path/to/v03/kernel/msm-4.19
```

Это тест совместимости формата и буферов на x86-64, а не измерение ARM64.
Прирост скорости, степени сжатия или автономности не заявляется.

## Boot и профили

Boot создан на основе проверенного v0.2; повторная распаковка подтвердила
идентичность ramdisk, DTB, header и fstab. DFE и checkpoint=fs сохранены.
Проверенный v0.2 boot и исходные резервные boot/vendor доступны локально.

GolfCore Profiles v0.1.1 распознаёт старое и новое имя. Его 13 host-тестов
прошли, в том числе при имитации нового релиза. Установленные на телефоне
проверки имени обновлены; исходный снимок и выбор CPU Balanced / память
balanced / автозапуск сохранены. Кодек ядра на телефоне пока остаётся старым.

После установки ещё предстоят проверка Android, штатных модулей, userdata,
звука, камеры, Wi-Fi, сенсора, пробуждения и применения профилей после
реальной перезагрузки. Наличие двух предупреждений NFC GPIO/device links
в базе и ограничения длительных тестов описаны в отчёте v0.2.
