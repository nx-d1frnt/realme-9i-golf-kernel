# GolfCore v0.2.0-rc1 — проверка устройства, 13 ноября 2026

Realme 9i 4G / RMX3491, crDroid GSI Android 14, существующая DFE-база.
Проверены артефакты из исходников commit
`b1550d249a1fade9a62a9bb631b9db4c21bae91d`.
Этот отчёт добавлен после сборки и не меняет её код.

## Установка и загрузка

- Перед установкой хеш текущего boot совпал с сохранённым рабочим ABI v2.
  Копии boot и vendor проверены и сохранены локально.
- После разрешения пользователя через fastboot записан только раздел boot.
- Android завершил загрузку. Фактическое ядро:
  `4.19.157-perf+ (golfcore@balanced-v0.2-rc1)`.
- Повторное чтение boot подтвердило SHA-256
  `392bdb8a70d1d91d6a4c4d4c4b7cd4a11f6e6a11ff6f84dbb4e8d9e1529462e9`.
- SHA-256 vendor остался прежним:
  `cd8e27d652e70cec886f40980b7cfe0f1926635124ff183c6a8521ae03b16b95`.
- Root доступен, userdata смонтирована как F2FS rw.
  Состояние crypto по-прежнему `unsupported`; существующий DFE сохранён.
- Все 31 ранее загружавшийся модуль загружены, список имён совпал полностью.
- Zram активен: LZ4, размер 4 GiB. USB-зарядка работает.
- Fingerprint HAL deaths=0; camera HAL видит две камеры.

## Экран и ручная проверка

Выполнены три автоматических цикла выключения и включения экрана.
Android переходил Dozing → Awake. В журнале после циклов зафиксированы
шесть вызовов touch resume и шесть завершений соответствующего рабочего потока.
Это проверка возобновления экрана, а не подтверждение глубокого сна системы.

Пользователь отдельно проверил сенсор, пробуждение кнопкой и двойным тапом,
Wi-Fi, звук/микрофон, камеру и отпечаток; ответ: «Всё работает».

## Журнал и ограничения

За первичную проверку до uptime около **277 секунд** в снятых журналах
не обнаружены kernel panic, Oops, BUG, ошибки ABI или подписей модулей.
Предупреждения `___slab_alloc`, `__alloc_pages_nodemask` и `irq_startup`
не повторились после загрузки и проверок экрана.

Остаются два известных предупреждения из базы:

| Место | Наблюдение |
| --- | --- |
| gpio_to_desc → pn544_probe | NFC probe получает GPIO -2; тот же стек присутствует в журнале предыдущего ABI v2, где начало предупреждения обрезано |
| device_links_driver_bound | Проверка состояния зависимости устройства во время probe |

Работоспособность NFC этим тестом не подтверждена. Предупреждения не скрывались.
Длительная стабильность, глубокий сон, расход батареи и сравнительная
производительность ещё не измерены. Статус версии остаётся экспериментальным.
Необработанные журналы и резервные образы устройства в Git не добавлены.
